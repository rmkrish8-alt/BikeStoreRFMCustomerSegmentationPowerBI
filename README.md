# 🚴 BikeStore RFM Customer Segmentation - Power BI

## 💡 Key Insight
> **89% Customers Lost!** But Loyal customers spend **4X more**

This project analyses 1,355 customers using the RFM (Recency, Frequency, Monetary) model.

## 📊 Dashboard Preview

## 🔍 Findings

| Segment | Customers | % | Avg Spend | Action |
|---------|-----------|---|-----------|--------|
| Lost | 1,206 | 88.99% | Low | Re-engagement Campaign |
| At-Risk | 138 | 10.17% | Medium | Retention Offer |
| Loyal | 9 | 0.70% | 4X High | VIP Loyalty Program |
